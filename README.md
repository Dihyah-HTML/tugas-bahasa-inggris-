# How to Initialize a Local Git Repository and Push Code to GitHub

## Goal
This guide explains how to initialize a local Git repository and push code to GitHub using Visual Studio Code. This project is for students of **Pengembangan Perangkat Lunak dan Gim (PPLG / RPL)**.

## Materials / Tools Needed
- A computer or laptop
- Visual Studio Code (Code Editor)
- Git installed on the system (Git Bash or Terminal)
- A web browser
- An active GitHub account
- An internet connection

---

## Task 1 - Writing a Procedural Text

### Steps

### 1. Create a New Repository on GitHub
Open your web browser, log in to your GitHub account, click the **"+"** icon in the top right corner, and select **New repository**. Give it a name (e.g., `my-first-project`) and click **Create repository**.

### 2. Open Your Project Folder
Launch Visual Studio Code and open the folder containing your project files.

### 3. Open the Integrated Terminal
Press `Ctrl + ~` or go to **Terminal > New Terminal** in the top menu to open the terminal inside Visual Studio Code.
